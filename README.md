# VOCA — English Vocabulary Hub

Интерактивная платформа для изучения английской лексики A1–B2.

Текущая версия: 200 карточек, 5 тем, 3 игры, практика и повторение. Прогресс хранится в браузере; задания учителя передаются JSON-файлами. ИИ и серверная синхронизация пока запланированы.

Подготовка GitHub Pages: index.html и src/ в корне, main / root. Публикация ещё не включена. Для Pages на GitHub Free репозиторий должен быть публичным; изменение видимости выполняется после подтверждения владельца.

В файлах сайта нет API-ключей или персональных результатов учеников.
